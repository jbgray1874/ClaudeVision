Matt, Charlotte,

A quick one on where the AI programme has got to. Short version: the estimating engine is live in a parallel run with our own estimators, the first go-live in the programme is this month, and all four workstreams are moving at once. Links below open the portal directly.

Estimating — live, five jobs a week

A CAD pack goes in; a fully costed estimate on our own template comes out, with a covering e-mail, a working report and a customer quote — e-mailed automatically the moment it completes. We are running it against the estimating team's own sheets at five jobs a week; Tim returned the first review line by line and every defect it surfaced was fixed the same day. As of this weekend all four documents read one costed record, and the report leads with the decisions an estimator still has to make. Go-live target: September / October, decided on reviews returned. After that it becomes one button: import the latest pack, estimate, explain, e-mail, quote.
SDI Estimating Intelligence · user guide · run page

Creative Design — first go-live in the programme, this month

SDI Drawing Search Intelligence went into UAT with the studio designers today — visual search over roughly 268,000 drawings and renders, so we find the fixture we have already built before anyone draws a new one. Studio-wide go-live ~25 September.
SDI Drawing Search Intelligence · user guide

Technical Design — two tools landing this month

The second Document Manager tool, Production Design Extraction, was demoed and approved on 2 September and is at 90% — it collects the shop-floor drawing pack automatically and says why anything was left out. P1 goes live 15 September, P2 on 29 September, then the in-house PDM builds through to February.

Manufacturing / CNC — the loop to the shop floor starts now

From this month Muhammad and I write this workstream's first record: mapping the live production spreadsheet for BOMs and routes on its way into Sage X3, and the design DXF process onto CNC machining — documented as a BRD and user stories before anything is built.

One piece of kit ties it together: the shared workstation hosting all three systems goes to order this week (£4.8–5.05k ex-VAT), racked by 10 September.
