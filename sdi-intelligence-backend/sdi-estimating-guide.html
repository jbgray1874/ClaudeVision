SDI Estimating Intelligence Guide

Start here — the one rule

Everything the engine produces is an estimate, not a quotation. It prices what the drawings actually show, states plainly what it could not read, and never invents a number to fill a gap. Where it cannot price something it says so rather than quietly costing it at zero — a line at £0 and a line nobody has priced look identical on a sheet, and only one of them is an under-charge.

So your job reading these documents is not to check arithmetic. It is to answer the questions the engine could not: which material is it really, which gauge, is that price still good, and does the offcut go on this job or to stock.

Running a job

On the estimating page: fill in number of units, drawing number and client, add the drawings, and press SDI (UK) Intelligence Estimator.

StepWhat to know
Number of unitsState it. With none given the engine assumes a default, and quantity drives real money — setup is spread across the order, and a one-off buys a whole sheet to make one part. A job priced at the wrong quantity is wrong by a lot, not a little.
Extract DesignDrawingPackAsks Document Manager to build the pack. A panel opens with the project number, customer and assembly folder already filled in from the Job panel — 10575-02 for Dyson gives 10575 / Dyson / 10575-02. Check the project is right before pressing Extract; that split is a guess at your numbering, not a rule. It takes minutes, on their host, and reports progress while it works. When it finishes the pack opens for you to choose from — it does not import everything, because the extract also writes candidate files and a selection report you would not want priced.
If the Document Manager API is not configured, this button browses the shares as it used to, and its tooltip says which of the two it will do.
Add job folder…The share browse. Point it at the job's own folder and every drawing in it is added. Not every job comes through Document Manager, and Document Manager is not always up.
Add drawing files…Use for a partial pack, or to add to what is already listed. Only the drawings on the list are priced — see below.
Add from Document Manager…A second source. Drawings from a Document Manager extract, merged into the same list. Same filename replaces, so a Document Manager copy lands on top of an older one from the share.
The ✕ beside a fileRemoves it from the list, whichever source it came from. A drawing you remove is not priced, and is not carried over if you run again.
Print drawings…Every drawing on the list as one PDF, bookmarked by filename, for checking the estimate against the pack. If something on the list cannot be printed — a DXF, a model — a cover sheet names it, so a part-pack is never mistaken for the whole one.
Estimating runnerMust show ready. The run happens on a machine with SOLIDWORKS and Excel; this page queues it.
Running the same job twiceRefused while the first is still going, and refused before anything is deleted. Staging clears this job's folder to fill it, so a second press would empty the folder the first run is reading and refill it with a different pack — the estimate would then price some mixture of the two, and the sheet would look entirely ordinary. A different drawing still queues freely.
Waiting behind another runOne estimate at a time per machine: SOLIDWORKS and Excel are driven on one desktop. The page says what it is waiting for and how long that has been running. If that run is dead — the machine slept, the runner was closed — its claim holds the queue for up to fifteen minutes, so Release the run in front of this one frees it. That releases the queue; it does not reach into a runner that is genuinely still working.
Output folderWritten to the estimating share, in a dated sub-folder, so re-running never overwrites an earlier estimate.

What gets priced is what is on the list — nothing more.

When you press the estimate button, the drawings on the list are copied into a folder of their own under AISheets\SDIIntelligenceAISheet\<client>\<drawing>\, and the engine reads that folder. The run log says so: Staged 7 drawing(s) into …. Check that number matches your list.

Run the same job again and that folder is emptied and refilled — so a drawing you took off the list cannot come back and be priced a second time. It also means the folder is a permanent record of exactly which drawings produced a given estimate, which is what you want when somebody asks about a number six weeks later.

1 · The Estimate sheet — the workbook you edit

This is the working surface. It is the estimating template you already know, populated. Every figure is an Excel formula, so it recalculates when you change an input.

The blocks, top to bottom

BlockWhat lands here
Bill of MaterialsBought-in parts — fixings, castors, pallets, packaging, delivery, powder. Priced per each, times the quantity per unit, plus scrap.
WireWire, bar and tube sections, costed by length. An empty Wire block means one of two things, and they are not the same. If the job genuinely has no sections, empty is correct. If the general arrangement shows a tube frame and this block is still empty, the sections were not read — check whether the pack included the models or detail drawings for them, because the frame is then not in the total.
Sheet SteelFabricated metal. Blank length and width, gauge, how many nest out of a sheet, cost per part.
Other Sheet MaterialBoard and plastic — ply, MDF, acrylic, Dibond. Same nesting arithmetic, different stock sizes.
LabourOperations grouped by process and material. Setup is booked once per tooling group, not once per part.
Rate calculatorsLaser, CNC and Powder — the template's own calculators, filled with the blank size, hole count and cut distance the engine measured.

Fabricated parts appear twice, and that is deliberate.

A part costed in Sheet Steel also appears in the Bill of Materials at £0.00, labelled "costed in Sheet Steel below". It is listed so the BOM is a complete parts list; pricing it in both places would double the material.

What wants your attention

You'll seeIt means
Shaded cells An estimator input. The engine has no rate and no input you supply elsewhere will fix it. Type the figure in and the sheet completes itself.
PROVISIONAL beside Unit Cost / Sell Price Outstanding inputs remain. The totals compute, but they are not a firm price until those are filled.
MATERIAL UNPRICED on a line That item has no rate anywhere the engine can reach. Enter a unit rate, or confirm it is something already in the catalogue under another code.
Margin 0% No commercial decision has been made yet. Sell Price equals cost until you set one.
AI ESTIMATE · INDICATIVE on a line A real figure, from a market estimate rather than a catalogue. It is not a quote and nobody has agreed it — it is there so the line is not £0 while you find the real price. Overwrite it before quoting firm.

A part is costed once, in one place. Fabricated parts are costed in Sheet Steel or Other Sheet Material and appear in the BOM at £0; bought-in parts are costed in the BOM and appear nowhere else. If you add a price to a fabricated part's BOM line, the job pays for its material twice.

2 · The AI Provenance tab — where each number came from

One row per part, naming the source behind every value and how strong that source is. This is where you go when a figure looks wrong and you want to know why it is what it is.

The strength words

WordMeaningWeight
CONFIRMEDAn estimator has already agreed this, and it was remembered.strongest
MEASUREDRead off the SolidWorks model or a DXF flat pattern — a measurement, not a reading.strong
REPORTEDPrinted on the drawing or in the BOM. Reliable, but it is what someone typed.good
ASSUMEDA default or an inference is standing in. Worth a glance.weak
UNKNOWNNothing supplied it. On a price this means nobody has priced it yet.gap

The summary line separates two different questions.

Engine read the drawing & model: 18 measured · 3 reported · 1 needs a look  |  Pricing: 13 priced · 9 awaiting your rate

How well the engine read the job is not the same as how much of it has been priced. An estimate is expected to arrive with prices outstanding — that is your half of the work, not a fault in the reading.

3 · The Decision Report tab — what the engine had to choose

Most values decide themselves: one strongest source, nothing contradicting it. This tab shows the ones that did not, because those are where your judgement is worth most.

Two blocks below the part table

BlockWhat it lists
Decisions that required resolution Operations. Two equally-ranked sources disagreed about whether an operation applies, and the arbiter settled it. The losing claim is named so you can check it.
What the part is — where two sources disagreed Material and gauge. The costlier arguments. Material sets the rate and whether the part has a rate at all; gauge sets the rate and steps the cut time — so a part costed on the wrong one is wrong twice. Widest disagreement first.

The higher-ranked source was used and the figure stands. What you are being asked is simply: confirm which is right before this goes out firm.

5 · "Drawings missing — priced from what we have"

An incomplete pack is priced, not refused. The engine costs every line it can read, leaves the undrawn assemblies uncosted rather than inventing metal and weld for parts nobody has seen, and states the gap in several places. The total is real for what was supplied — it is not a price for the whole product.

Where it showsWhat you see
Job report — Drawing packThe fullest account: which drawings the BOM names that the pack does not contain.
Job report — Estimating reviewListed with the part numbers and descriptions. These used to be marked "blocking". That word has gone: it set one internal flag, three rules raised it on every job regardless, and it read as a refusal the engine was not entitled to make. The engine reports the BOMs, the routes and the prices with their sources — the judgement is yours.
Estimate sheetA red block below the estimator-input checklist: DRAWINGS MISSING FROM THIS PACK (N) — each part named, with "priced from what was supplied; these are NOT in the total above". The sheet also stays marked PROVISIONAL.
AI ProvenanceA line stating which parts the tab is not about — a part with no drawing has no row worth reading, so it is named rather than left out silently.
Decision ReportDRAWINGS MISSING FROM THIS PACK — NOTHING DECIDED, NOTHING COSTED. Every other block on that tab describes a decision made from evidence; these parts had none.
Run logNamed at the end of the run in the invariants block.
Client quoteNothing. The customer's page carries the price and the specification, labelled indicative. What they are told about scope is yours to say, in your words.

What to do: quote provisionally on what is priced and say which assemblies are excluded, or ask for the detail pack and re-run. A thin total on an incomplete pack is an incomplete pack — not a cheap job.

6 · The client quote — what the customer sees

Deliberately the plainest document of the set. It carries the price, the specification, what is included, and nothing about how the engine reached it.

  • The price is labelled indicative everywhere it appears.
  • Internal reasoning — invariant names, confidence, engine workings — never appears on it.
  • It is generated from the job, so the material, finish and operations shown are the engine's reading of the drawings.

7 · Re-issuing a quote after you have edited the sheet

When you have amended the workbook — filled the rates, corrected a price, set a margin — the portal can turn your version into a fresh client quote.

  1. Edit and save in Excel. This matters: the totals are formulas, and the values are only stored once Excel has recalculated and saved them.
  2. On the estimating page, fill in units, drawing number and client.
  3. Choose amended workbook… and pick your saved file.
  4. Press Estimator Client Report Regen.

You get a client quote carrying your figure — Sell Price if you set one, otherwise Unit Cost — plus a copy of your sheet saved as the manual-override record. No drawings are needed and none are re-read; the engine does not run again. The job report and provenance tab are left as they were, because they describe the engine's estimate, not yours.

If the quote comes back saying "As drawing" everywhere, this is why.

The regenerated quote keeps the material, finish, operations and the GA image by reloading the original run's saved job file. It looks that up by the job's stem and by the workbook's own name, so a renamed sheet usually still resolves — but the original run's output must be on this machine. Where it cannot find the job you still get a quote, and the page now says so in amber, names the .json it looked for, and tells you it lives on the machine that ran the estimate. Check that before sending: a thin quote renders exactly like a complete one.

Two ways to name the sheet. Choose from share… browses the AISheets folder — the estimate workbooks this engine wrote are already there, under the client and job, and that is the usual route. Upload… is for a sheet that is not on the share: one that came back by email, or one kept locally.

8 · Parity — your estimate against the engine's

The one report that answers "is this thing any good?". It compares the engine's own reading of a job against a manual estimate for the same job — not sheet against sheet, but the engine's full working against your number, so you see where the two part company rather than only that they do.

It reports the unit cost each side arrived at, the gap between them in pounds and per cent, and then the part that matters more: how many money cells and route lines agree. Two totals landing close together while thirty cells underneath disagree is a coincidence, not a validation, and the counts are what tell them apart.

Two ways in, and which to use

You are…Use
About to run a job you have a manual estimate for On the Job panel, Choose manual estimate… before you press the estimate button. The comparison is produced with the rest of the deliverables — you name one file, because the engine is about to produce the other.
Looking at a job already estimated, maybe months ago The Parity report card. Name both sides, because both already exist. No re-run, no drawings, no runner — this is how the back catalogue gets compared.

On the card, the AI estimate can be the engine's workbook rather than its .json: the summary is found from the workbook's filename, so the spreadsheet you were sent is enough. Do not rename it — that is how it finds the job. The manual estimate can be .xls; most of the back catalogue is.

You are not asked for units. The quantity is read off the manual sheet and both sides are compared at that quantity, so nothing you type can disagree with the sheet.

"Unit costs could not both be read" is not a failure — it is the honest answer.

A workbook the engine wrote and nobody has opened in Excel holds formulas with no calculated values. There is genuinely no number in the cell to compare. Rather than show £0.00 — which looks like a real figure and would make the engine appear infinitely over — it says it could not read them. Either tick Resolve formulas through Excel, or open each sheet in Excel and save it once, which fixes it permanently.

Check the quantities match before reading much into a gap.

If the manual estimate was priced at 45 off and the engine ran at 10, the comparison still works and normalises to 45 — but the engine's figure carries 10-off setup spread across it. The difference you are looking at is then partly quantity, not accuracy.
